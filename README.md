# FairShare 

FairShare is a mobile application project built with Flutter and Dart to help people manage shared expenses fairly and transparently.

The goal is to make it easier for friends, roommates, couples, and other groups to record shared costs, calculate each person's share, and keep track of outstanding balances.

## Project Goals

- Record shared expenses.
- Identify who paid for an expense.
- Calculate how much each participant owes.
- Track repayments and outstanding balances.
- Explore Firebase for authentication and cloud data storage.

## Technologies

- **Flutter** — cross-platform app development.
- **Dart** — programming language.
- **Firebase Authentication** — planned user registration and login.
- **Cloud Firestore** — planned cloud database.

## Current Status

The initial Flutter project has been created and pushed to GitHub. The application features are still being developed.

## Planned Features

1. User registration and login.
2. Create and manage shared groups.
3. Add expenses and select participants.
4. Calculate balances between group members.
5. Record repayments.
6. Store group and expense data using Firebase.

## Scope and Safety

FairShare is intended to record and calculate shared expenses. It will not hold funds or transfer money between users.

## Running the Project

Make sure Flutter is installed, then run these commands from the project directory:

```bash
flutter pub get
flutter run
```
